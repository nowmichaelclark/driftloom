# What is in the app, and under which license

The repository is MIT (`LICENSE`). Everything the release APK holds is listed
here. `fdroid/check-apk.sh` (CI, `.github/workflows/fdroid.yml`) fails when the
release's runtime libraries are not exactly the libraries listed below, so
this file cannot drift from the APK. Every license here is free software under
F-Droid's inclusion policy; nothing is proprietary, nothing is downloaded at
run time, and the APK asks for no network permission.

## The app's own work: MIT

| What | Where |
| --- | --- |
| The page, its worklet and its data (the app's files, `assets/www`) | `index.html`, `js/`, `css/`, `data/` and the rest of `sw.js`'s list |
| The audio core as a WebAssembly module (`js/dlplayer.wasm`), built from `core/` | Rust, `core/`; no third-party crate (`core/Cargo.lock` lists this repository's crates only) |
| The audio core as native code (`libdriftloom.so`, three ABIs), built from `android/native` and `core/` | Rust, built with the NDK; no third-party crate (`android/native/Cargo.lock`) |
| The app's code | Kotlin, `android/app/src` |
| The icons and the launcher icon (the orbit mark, drawn as vectors) | `icons/`, `android/app/src/main/res` |
| The silent keepalive loop (`audio/keepalive.flac`) | generated by `tools/keepalive.py`; no sampled sound |
| All the loops' sound | synthesized by the core at run time; no recorded sample ships in the app |

## Anti-features

F-Droid's anti-features, checked by `fdroid/check-apk.sh` and by reading the
manifest: **none apply.**

- *Ads, Tracking*: no ad, analytics or crash-reporting library (the script
  searches the code for the usual ones); the WebView's own Safe Browsing and
  metrics are turned off in the manifest.
- *NonFreeNet*: the app talks to no network service and has no network
  permission; the page is bundled and never reaches the network.
- *NonFreeDep, NonFreeAdd*: no Google Play Services, no proprietary library;
  the WebView is the system's, as for any app that shows a web page.
- *NonFreeAssets*: the fonts are OFL, the sound is synthesized, the icons are
  this repository's own.
- *KnownVuln*: none known for the libraries above at the time of writing (the
  versions are pinned in `app/build.gradle.kts`).
- *UpstreamNonFree*, *NoSourceSince*: the source is public and MIT.
