# docs/ears: what the ears sessions write

The reports, plan, album cards and raw data from the ears sessions. These
lived in the Procedural Music App Project until 2026-10-17; Mikey asked for
them in the repo, and for it to be a rule (the first section of
`sessions.md`): **ears outputs live in the repo.** The scripts they use are
in `tools/ears/`; the findings and yardsticks distilled for the brain and
hands are in `docs/EARS.md`.

| File | What it is |
|---|---|
| `sessions.md` | Read first. What ears sessions are for, the repo rule, lessons, practical notes (Drive, pushing, piles). |
| `plan.md` | Every album on the list, the card format, the session split, costs. Read second. |
| `batch-1.md`, `batch-2.md` | The first two batches: 32 albums measured against Driftloom; the six differences. |
| `batch-3.md` | The waiting sounds and the first stereo round (Ears 2). |
| `batch-4.md` | The tune round (Ears 4): every sketch approved, the chapel organ, stereo's baseline. |
| `cards-test.md` | The two test cards (*Geogaddi*, *Galaxy Garden*) the card tools produced in Ears 3. |
| `cards-pile-1.md` | Pile 1 album cards (Ears 5): Aphex Twin 1992-94 and Polygon Window. |
| `prototypes.md` | The first sketches (Ears 1; the app branch they lived on went wrong, so ideas only). |
| `space-sketch.md` | The stereo recipes as a diff (Ears 2; a reference, never app code). |
| `tools.md` | Ears 1's scripts as written then. The current versions are in `tools/ears/`. |
| `uploads.md` | The records still to upload to Drive, by pile. |
| `data.csv` | Raw per-track measurements for batches one and two and 104 Driftloom loops. |

New cards go in `cards-<pile>.md`, new batches in `batch-N.md`, in a PR from
the session that wrote them.
