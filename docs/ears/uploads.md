# Albums to Upload

Everything the ears still need in Drive: 60 records in 9 piles. Upload
**whole albums** unless the Notes column says otherwise.

**How:** run `driftloom-ears.sh` (in `tools/ears/`) on each album's
folder or zip. It makes the small Opus files and keeps every file under
5.5 MB, so no other step is needed. Put each pile's albums in their own
folder inside the "Driftloom" Drive folder, named `for-claude - pile 1`,
`for-claude - pile 2`, and so on, with one subfolder per album. Any order
works; pile 1 is the one the first card session (Ears 5) will reach for.
