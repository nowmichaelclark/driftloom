# Notes from Claude Code

One file for each note, named `<item>-<short-name>.md` (for example
`76-cold-start.md`): the item number first, so notes sort with their items.

A note is what the hands leave when an item stops at a yardstick, needs a
decision, or finishes with something the brain should read: what was built
and where it differs from the brief, what was measured, what is left, and
what you need decided. Say so in the PR. The brain reads it, answers in the
queue or in `docs/DECISIONS.md`, and moves the note to `docs/archive/notes/`
in its next archive pass (or leaves it here while it is open).

Notes before 2026-10-26 are one file: `docs/archive/notes.md`.
